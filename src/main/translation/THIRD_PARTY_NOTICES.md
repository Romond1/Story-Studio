# Local translation dependencies and models

- Mozilla Firefox Translations released en-ja 3.0 (base-memory), en-it 3.0 (base-memory), en-ro 3.0 (tiny translation architecture; unrelated to Whisper Tiny). MPL-2.0. Source: https://github.com/mozilla/translations and https://github.com/mozilla/firefox-translations-models . The exact Mozilla Remote Settings records, SHA-256 hashes, compressed and expanded sizes are in models.json, captured 2026-10-12 from https://firefox.settings.services.mozilla.com/v1/buckets/main/collections/translations-models-v2/records . Model binaries download from Mozilla's attachment CDN, not the archived model repository.
- @browsermt/bergamot-translator 0.4.9 (packaged WASM identifies v0.4.5+4917c11), MPL-2.0. Unmodified upstream package from https://github.com/browsermt/bergamot-translator . bergamot.cjs adapts its browser worker environment to Node; no fork of the engine.
- whisper.cpp v1.8.2 CPU Windows x64, MIT. Official archive https://github.com/ggml-org/whisper.cpp/releases/tag/v1.8.2 . Version chosen for its released Windows binaries; newest source release is not substituted automatically. Runtime SHA-256 pinned in whisper.cjs. ggml/whisper shared libraries are included in that archive.
- Resident `whisper-host.exe`: project native pipe wrapper around those same libraries. Source/build recipe and pinned v1.8.2 ABI headers are under `native/whisper-host`; the upstream MIT license is copied into the packaged translation directory. Host SHA-256/size are verified before launch. The wrapper uses the static MSVC runtime; the upstream downloaded DLLs retain their existing runtime requirements.
- Optional GPU runtime: the same release's `whisper-cublas-12.4.0-bin-x64.zip`, SHA-256 `54a3c012e6c567e2e8bed874cdf49c55f018ec8d90bb5d5271568aa573291b2d`. Downloaded on compatible Windows x64 NVIDIA systems, not bundled for every platform. Includes NVIDIA CUDA runtime/cuBLAS/NVRTC libraries, which have NVIDIA's own terms: https://docs.nvidia.com/cuda/archive/12.4.0/eula/index.html . These libraries are not covered by whisper.cpp's MIT license. A compatible NVIDIA driver is required; no CUDA development toolkit/compiler is required for this prebuilt runtime.
- OpenAI Whisper base.en (default) and small.en (optional), MIT. Converted ggml models from https://huggingface.co/ggerganov/whisper.cpp with pinned SHA-256 and sizes in whisper.cjs. Model source: https://github.com/openai/whisper . Only the selected model is installed.
- Kuromoji 0.1.2, Apache-2.0, https://github.com/takuyaa/kuromoji.js . Bundled IPADIC data retains its NAIST/ICOT notice in LICENSE-IPADIC.txt. This mature analyzer is old and not actively updated; unknown names and ambiguous readings need manual review/correction.
- fzstd 0.1.1, MIT; extract-zip 2.0.1, BSD-2-Clause. Their original license files ship in their npm packages.

These licenses permit commercial use subject to their terms and redistribution notices. No general-purpose LLM, cloud inference, paid API or API key is used. Keep these notices and dependency license/source references with distributions. No claims are made about linguistic fitness for a particular lesson.
