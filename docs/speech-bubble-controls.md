# Speech bubble editing

The Speech bubble Inspector offers Classic speech, Thought, Shout, Oval speech and Plain box (no tail). Speech, oval and thought styles have Bottom Left / Bottom Right / Top Left / Top Right tails. Only the vector and its safe text area mirror; lettering stays upright. Shout and Plain box ignore retained tail settings. Older bubbles retain Classic and bottom-left defaults without migration.

Text fits the bubble's usable region before paint, using measured wrapped text and 1.05 line spacing. The Font size setting is a maximum: text scales down with geometry and can shrink further for longer dialogue. Resizing back up restores the available size, without modifying authored text or its maximum font size. Extremely small bubbles with long text can naturally become too small to read; enlarge the bubble or shorten the dialogue.

Show from (seconds) and optional Show until (seconds) define a visibility range, up to one hour. Leaving the end blank retains the previous stay-visible behavior. Teach and Present use source-video playback seconds for video scenes, including pause, seek, trim start and replay; Teach uses the shared transport position rather than the preview stream's own clock. Image scenes use elapsed scene-entry time. Edit and passive timeline thumbnails always show all bubbles. A video observer/event/frame subscription or next-boundary still-scene timeout is cleaned up on navigation and unmount. Ordinary viewport or plan updates do not restart timing. Boundaries crossed before effects run trigger an immediate refresh.

Optional `bubbleTail`, `appearDelayMs` and `disappearAtMs` fields are validated in documents and whitelisted in render plans, dependency inspection and portable episode metadata. The end must be later than the start. Editing uses existing Undo/Redo and save/reload. Edit video controls now display current source-video time / total duration to hundredths as a separate readout from trim endpoints.
