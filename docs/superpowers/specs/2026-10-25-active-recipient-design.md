# Persistent reward recipient

Show a compact Reward recipient badge to the left of teacher notifications, below the header. Use the session reward student directly, so F1 and menu changes stay synchronized. Keep it visible in Edit and Teach while a lesson is open; show No student selected when needed. No change to Present. A badge beside notifications keeps the name near feedback without modifying the header or preview. Use a responsive flex dock to prevent overlap.

Compact follow-up: the badge is a single 32px row within the phase strip. The F1 hint and full recipient name are available on hover; long names truncate rather than increasing height.
