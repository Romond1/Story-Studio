Phases: ready → selecting → revealed → active → activity-complete → selecting, or session-complete when the configured turns are consumed. Actions carry expected runtime revision/configuration key plus session, visit and occurrence scope, preventing delayed/double dispatch across navigation and resets. Random entropy is generated once by a Teach event handler and carried in the action; the pure adapter selects a configured segment, retaining its ID for future animation. Alternating starts with questions, random honors remaining quotas, teacher selection uses only eligible assigned segments.
