# Phase 2.5 Teach workspace design

Keep Edit composition and shared Core session. Teach uses one preview/control split and a bottom semantic navigator. Reusing the old three columns wastes control space; replacing the scene engine risks duplicated effects. A separate composition around existing interactive renderers is the chosen approach.

Present reports its actual .present-surface viewport through the authenticated existing IPC bridge. Keep logical scene frames stable: both surfaces contain the same frame inside matching viewport ratios. Control fits that viewport into available space. Pointer input is confined to the logical content rectangle. Closing Present retains geometry and workspace; reopening restores transport without navigation changes.

Teach controls include active student/rewards, live audio/music, canonical navigation, drawing/viewport, media transport, existing board actions and movement. Secondary controls reuse existing panels in a details drawer; authored editors remain Edit-only. Divider preference is localStorage only. No routing, game, reward engine or lesson schema redesign.

Verify pure geometry (including letterboxes and stable logical coordinates), lifecycle and capability boundaries, existing tests, renderer typecheck and renderer/main builds. Perform limited rendered layout inspection, leaving exhaustive live lessons and conferencing capture to the user.
