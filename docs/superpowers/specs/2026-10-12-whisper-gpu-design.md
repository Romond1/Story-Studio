# Optional Whisper CUDA acceleration

Keep whisper.cpp 1.8.2 and its existing verified GGML Base English / Small English models. Add the official Windows x64 CUDA 12.4 archive as an optional, integrity-checked download. CPU retains its independent small runtime and explicit no-GPU flag. Auto probes NVIDIA availability before attempting CUDA, and falls back visibly if installation, loading, or backend verification fails. Explicit GPU fails with recovery instructions. Actual backend must come from native initialization logs, including CUDA model/compute buffers, not the selection preference.

Keep native inference in the existing child process, installation/hash/extraction in the worker, and asynchronous orchestration in Electron main. Cache successful runtime preparation within the worker to avoid repeatedly hashing hundreds of MB and extracting DLLs. Across worker lifetimes, verify installed executable/DLL files with a pinned per-file SHA-256 manifest and extract only on missing/corrupt files. This addition addresses the measured 106-second redundant extraction in the live test. Each utterance still loads and releases its native model; report this explicitly in cold/warmed-process-cache benchmarks. Retaining CLI rather than a persistent HTTP server preserves decoding behavior, cancellation semantics, and the small integration boundary. A persistent provider can be evaluated separately if load overhead remains material.

Expose Auto/GPU/CPU, verified backend/device and initialization/inference timing. Switching cancels pending inference, waits for native closure and releases prior resources. Preserve translation, Japanese formatting, rendering, camera, tracking, schemas and audio routing.

Validation: backend parser/selection and failure-path tests, cancellation tests, four real hardware configurations with five warmed trials each, identical fixtures, separate translation timing, CPU/RAM/GPU/VRAM sampling, and camera/tracking/video contention.
