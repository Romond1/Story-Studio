# Import duplicates and type grouping

File picker, folder and drag imports share filename conflict handling. It compares the original basename including extension, case-insensitively, against the current in-memory catalogue (including unsaved imports) and earlier files in the same batch. No content hashing is performed: differently named files remain separate, and same-name files prompt even if their bytes differ. Old projects are not automatically deduplicated.

The native dialog offers Keep existing or Use incoming, with a checkbox to reuse that decision for the rest of the current import. Closing the dialog keeps the existing item. Incoming replacement keeps the asset ID, display title and bin, copies to a fresh UUID storage path, and registers explicit replacement metadata. Old physical bytes remain for Undo/recovery; source files are never changed. New assets in a batch retain only one item and one scene wrapper per filename. A skipped file adds no authoring history revision. Legacy schema-owned path references are remapped along with metadata; arbitrary text is untouched.

The Type ↕ button beside Search media toggles stable images-first, videos-next, audio-last grouping. It is off by default, local to each bin for the current editor session, and preserves order within each type. Toggling off restores authored order. It does not alter timeline ordering, assets, IDs or save data. The button is available in both lesson and legacy Media Pools.

Bin management includes New bin, Rename bin and Remove bin. Choose a user-created bin to enable Rename/Remove; General / all media is permanent. Removing a bin moves its direct media and child bins to its parent (or General media) without deleting media files or scene references. Rename and removal use existing project Undo/Redo and save/load. Native `scripts/media-bin-actions-smoke.cjs` verifies rename/cancel, root protection, nested-bin preservation, undo/redo and actual save/reload; focused unit coverage checks immutable snapshots and stable IDs.

Changed areas: main importer and import IPC, preload/API context, ImportResult replacement validation, lesson/legacy merge functions, MediaPool components, and focused regression tests. `scripts/media-import-duplicates-smoke.cjs` checks actual Electron imports/dialog decisions, bulk/drop IPC, unsaved duplicate detection, undo/redo and references, plus per-bin grouping. Unit coverage includes old-byte preservation, within-batch conflicts, stable sorting, legacy audio path remapping and unchanged undo snapshots.
