# Phase 2 manual teaching acceptance

Automated checks use synthetic fixtures. These checks establish whether the real
lesson still feels and sounds correct; they are not yet recorded as passed.

1. Open an existing episode yourself. Launch Present, share that window in the
   conferencing app, and navigate slides and sections entirely from Control.
   Compare imagery, text/bubbles, adjustments, transitions and layout.
2. Resize both windows, including a narrow Present window. Draw a marker and a
   highlighter, zoom, pan, reset, clear, navigate away and return. Check saved
   markers after saving/reopening a test copy where persistence applies.
3. Open a break and a board. Check timer pause/run behavior, card reveal/hide,
   drag, shuffle, duplicate references, half-stage layouts and navigation return.
   Reload Present and confirm timers/layouts do not restart.
4. Play a video, pause, seek and replay. Check trim boundaries and media volume.
   Listen through the actual conferencing route: video audio must occur once,
   lip sync must be acceptable, and microphone, music, dialogue and SFX must work
   normally. Check monitor versus broadcast routing with your existing settings.
5. Trigger movement, Sparks, badge celebration and Relic progress/reveal. Check
   visuals, configured sound, totals and progress. Reload Present during an
   effect: no repeated award, sound or expired animation. With a longer class
   list, scroll badge results in Control and verify Present shows the same rows.
6. Enter each existing booster sequence, navigate and interact with its content,
   then return to the exact story location. Check missing references and future
   unsupported activities show a clear fallback rather than an old slide.
7. Close/reopen and reload Present during video playback. Recovery should be
   paused, preserve the lesson in Control, and allow deliberate resumption.
   Reselect the new window in conferencing when it has been recreated.
8. Use normal teaching fallback and re-enter Present. Confirm one media executor,
   normal microphone/music routing, and retained lesson location. If available,
   move Present to a second monitor and test display removal/reachability.
9. Check shortcuts while typing in text fields and outside them. A command should
   fire once; holding a reward key must not repeatedly award. Present should not
   independently navigate or accept teacher shortcuts.
10. Repeat representative checks across Episodes 1–5. Record any visual, timing,
    sound or navigation regression before deciding whether Present is ready for
    a real class. Keep the legacy teaching path until that decision.

Real audio-device availability, conferencing capture/re-sharing and physical
lip-sync acceptance require this manual pass. The implementation does not repair
or replace virtual audio drivers.
